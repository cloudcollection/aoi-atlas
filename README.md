# AOI 多地图采集

从高德、百度地图采集建筑物与园区的 AOI 边界，支持腾讯地图地点采集。提供 Chrome / Edge 扩展和本地 Web，支持预览及 GeoJSON、CSV 导出，Web 另支持 SHP。
