# 验证记录

日期：2026-10-16，Asia/Shanghai。Windows 11、Edge、Python 3.12。以下区分真实在线操作、自动回归和本地模拟；截图均为实际运行界面。

## 本版真实地标操作

- 百度扩展：正常搜索并点击广州图书馆，捕获 UID `7acd94c994a1321a02ec0144`，保存 12 点来源轮廓。来源 `is_precise=0`，提示及标记保留。不是楼栋轮廓或自行描画。
- 百度 Web 在线采集：正式采集入口启动独立 Edge，正常搜索广州图书馆并在 Web 浮窗点击保存，实际回传成功并生成 12 点边界文件。随后通过工作台实际下载 GeoJSON 和 SHP 套件，核对双来源、点数及几何有效性。
- 腾讯扩展：正常搜索深圳人才公园，保存 UID `13178396489244734153` 的 Point。打开独立 `/poi/` 详情页后，实际 `mapsearch?qt=rich&pid=...` 返回 `detail.baseInfo`；新增适配通过真实浮窗保存。
- 腾讯详情通过请求公开 `pid` 关联地点 ID，不从名称推断匹配；来源分类与电话保留在备份、GeoJSON 和 CSV。当前公开地标响应没有验证到可用 AOI 面。
- 扩展工作台仅使用广州图书馆和深圳人才公园记录；通过真实备份恢复到独立 Web 演示库，检查预览和实际导出。

## 底图与画面验收

- 发现在线底图服务会返回可加载的 HTTP 403 错误图片，普通图片加载事件无法可靠识别。新版默认本地 WGS-84 坐标网格，显示来源轮廓、地点名称、坐标和比例尺。
- 用户可切换在线底图；预检和瓦片 HTTP 检查失败后自动切回网格，不持续堆叠错误图块。
- 真实 Edge 工作台中模拟底图 403 响应，验证自动回退、网格仍存在、记录保留。此项只模拟底图故障，不伪造来源几何或保存状态。撤销模拟后通过正常网格选项拍图。
- 截图统一为 1440×960，完整显示主要工作区，地图采集页聚焦具体地标。没有修改截图中的数据、边界或保存状态。

## 已有验证及限制

高德新版扩展已有真实 44 点来源边界保存与浏览器重启后读取证据，并与百度同名 ID 隔离回归。Web 高德独立浏览器曾遇到网站安全验证，因此没有将这次 Web 在线检查计为成功；共享解析器、Web 浏览器保存桥接和文件导出分别通过。实际使用遇到登录或验证时，需要在原页面人工完成。

之前的真实 Web 浏览器桥接测试，使用已实采的百度候选通过 CDP 队列回传，验证保存与回执，并检查当前标签页未被切换。每次先移除测试自己的旧记录，防止旧数据误通过；此项属于记录重放，不是新的在线搜索。

百度已验证单环编码；多环源编码未验证时拒绝。坐标转换和几何有效性不代表测绘准确性。夹具不包含 Cookie、认证参数、浏览器配置或账户状态。
